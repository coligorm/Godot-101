## Godot University:

I found a video by [Pink Hoodie Dev](https://www.youtube.com/@PinkHoodieDev) called [the godot game development tutorials you need to watch](https://youtu.be/2ifq1k-B0oY?si=aC4nCIILkntt4yQ5) which outlines important tutorials to watch for Godot in a college style.

The aim is to replicate a University style learning.
- Taking an important topic/class
- Learning from the lecturer (or in this case, YouTuber)
- Following along and creating a mini project based on the class
- Then creating my own mini project on the previous item learned
- Repeat the next class
- Then combine what is learned into a bigger "final" project
